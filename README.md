## ⚡ Engineering & Architecture Highlights

- **Static Site Generation (SSG):** Built with Astro for instant Time to First Byte (TTFB) and zero server runtime overhead.
- **Speculation Rules API:** Pre-renders bilingual routes (`/` and `/pt/`) in background for near-zero millisecond language switching.
- **Structured Data & SEO:** Full Schema.org `ProfilePage` & `Person` JSON-LD graphs, automated `sitemap.xml`, `robots.txt`, and `llms.txt` for AI search discovery (Perplexity, ChatGPT Search).
- **Self-Hosted Typography:** Zero Layout Shift (CLS) through preloaded variable fonts (`Newsreader`, `Inter`, `JetBrains Mono`) with restricted unicode ranges.
- **Modern Styling Pipeline:** Tailwind CSS v4 paired with LightningCSS for lightning-fast build-time CSS compilation and minimal bundle size.

## 🚀 Getting Started

### Prerequisites
- Node.js 20+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/BlackDereker/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Production Build

```bash
# Build static production assets into dist/
npm run build

# Preview production build locally
npm run preview
```
